PHYSLAB v15 — обновлённая сборка

Что обновлено:
- Новый тёмный научный интерфейс с адаптивной вёрсткой.
- Переработаны главный экран, карточки и навигационные состояния.
- Добавлен интерактивный экспресс-эксперимент «Бросок под углом» на главной странице.
- Скорость и угол меняются ползунками; траектория, дальность, время и максимальная высота пересчитываются автоматически.
- Обновлена версия кэша Service Worker, чтобы браузер забрал новые файлы.
- Существующие лаборатории, профиль, поиск, отчёты и остальные исходные модули сохранены.

Запуск локально:
1. Распакуйте архив в одну папку.
2. Откройте папку через локальный веб-сервер (например, расширение Live Server в VS Code).
3. Откройте index.html через адрес локального сервера.

Публикация на действующем сайте:
- Загрузите содержимое этой папки в корневую папку сайта с заменой старых файлов.
- Если сайт размещён через GitHub Pages / Netlify / Vercel, загрузите обновлённые файлы в репозиторий и выполните deploy.
- После публикации сделайте жёсткое обновление страницы (Ctrl+Shift+R). Service Worker использует новый cache id physlab-v15.

Важно:
- Эта сборка подготовлена из файлов, загруженных в чат. Она не публикует изменения на внешний хостинг автоматически: для этого нужен доступ к вашему хостингу или репозиторию.
- Конфигурация Google OAuth и остальные исходные настройки сохранены без изменения.
